# Team Notes Hub — ตัวอย่างอินเทอร์เฟซ (demo)

### ▶ [เปิดตัวอย่าง](https://olay097056.github.io/team-notes-hub-demo/)

ตัวอย่างหน้าตาของ **Team Notes Hub** แอปเว็บขนาดเล็กสำหรับใช้ร่วมกันในทีม
เก็บคู่มือ โน้ต และไฟล์ — แถบโฟลเดอร์แบบ Finder, ช่องค้นหาที่พร้อมใช้ตลอดเวลา
และเข้าสู่ระบบด้วยรหัสผ่านร่วม แอปจริงสร้างด้วย Next.js + PostgreSQL และรันอยู่
ภายในบริษัท ดังนั้นซอร์สโค้ดกับเนื้อหาจริงจึงเป็นแบบส่วนตัว

**ทุกอย่างในหน้านี้เป็นข้อมูลสมมุติ** หน้านี้เป็นเพียงตัวอย่างอินเทอร์เฟซแบบ
static แบบอ่านอย่างเดียว ทุกโฟลเดอร์ โน้ต แท็ก และข้อความถูกสร้างขึ้นเพื่อให้
หน้าตาเหมือนกับเครื่องมือจริง — ไม่มีเนื้อหาของทีมจริง และไม่ได้เชื่อมต่อกับ
ระบบใด

## ตัวอย่างนี้มีอะไรบ้าง

**แถบโฟลเดอร์** — การนำทางแบบ Finder พร้อมโฟลเดอร์ แท็ก และถังขยะ คลิกโฟลเดอร์
เพื่อดูโน้ต คลิกแท็กเพื่อกรองข้ามโฟลเดอร์ หรือคลิก Trash เพื่อดูรายการที่ลบแล้ว

**ช่องค้นหา** — ช่องค้นหาที่พร้อมใช้ตลอดเวลา กรองโน้ตทุกตัวจากชื่อและเนื้อหา
เหมือนในแอปจริง

**หน้ามุมมองโน้ต** — ตัวอย่างโน้ตแบบ Rich text ตามที่ตัวแก้ไขจัดเก็บไว้ ไม่ว่า
เช็กลิสต์ ตาราง โค้ด บล็อกคำพูด หรือหัวข้อย่อย

## เกี่ยวกับแอปจริง

Next.js (App Router) + Tailwind CSS, PostgreSQL และ Docker Compose สำหรับรัน
ในเครื่องและใน LAN (เสริม Caddy HTTPS ได้ถ้าต้องการเปิดใช้บนอินเทอร์เน็ต)
ใช้รหัสผ่านร่วมเพียงตัวเดียวไม่ต้องมีบัญชีต่อคน เพราะ PRD ระบุว่าเป็นเครื่องมือ
สำหรับทีมเล็กที่ไว้ใจกัน มีการสำรองข้อมูลอัตโนมัติทุกวันเป็นแนวทางกู้คืน
เพราะตัวแก้ไขไม่มี undo เนื้อหาโน้ตใช้ Tiptap v3 รองรับ Rich text

ถ้าสนใจตัว repository ส่วนตัว เชิญขอได้ครับ
